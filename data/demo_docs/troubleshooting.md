# ServiceFlow 演示排障知识

本文是可导入知识库的示例，不表示系统已访问用户设备或真实服务器。

## Docker 无法连接

遇到 npipe/docker_engine 不存在，先启动 Docker Desktop，确认 Linux containers，再检查 docker version 是否同时返回 Client 和 Server。检查 context 与 WSL 状态；不要把清空数据卷当作第一步。

## 无法打开聊天页面

本地聊天入口是 http://localhost，API 与 Swagger 在 8000 端口。检查 nginx 和 serviceflow 容器状态，确认端口没有冲突。云端演示使用实际 HTTPS 地址并先登录。

## 模型认证失败

401 通常需要核对模型凭据，403 需要检查权限和账户状态。只在本地或平台私密环境变量中修改 Key，不发送到聊天或公开日志。

## 检索与记忆

先检查 Chroma 实际运行模式和文档数量。改写失败会回退到原查询，重排失败会回退原候选顺序。相同用户和会话才能复用对应工作记忆；公网演示数据可能在实例更换后丢失。

## 账单争议

当前服务只能提供字段检查与规则说明，不连接真实支付系统。提供脱敏订单号、日期、金额和支付渠道后，由实际业务方核验，不承诺自动退款或到账。

## 安全

不上传密码、验证码、API Key、Token 或银行卡完整信息。涉及删库、删除卷或覆盖配置时，应先备份、明确目标并取得授权。
